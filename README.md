# heyaconvivialite.fr

Site marketing + CMS admin pour Heya. Stack : Nuxt 4, Nuxt UI, NuxtHub (D1/R2/KV), Better Auth, Comark.

## Commandes

```bash
pnpm install
pnpm dev
pnpm lint
pnpm typecheck
pnpm db:migrate
pnpm task:seed-admin
```
